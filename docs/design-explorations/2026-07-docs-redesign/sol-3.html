Orientation

Design judgment,
available at the prompt.

RavenMCP is a design-intelligence MCP server. Install it, point your coding agent at it, and it audits pages/layouts/screens, generates design systems and tokens, and carries your taste across projects.

MCP server70 tools9 knowledge layersHuman + agent readable

Quickstart

Three moves.

route / install
01

Install

npx @ravenmcp/cli install (or add to your MCP client config manually)

02

Connect

restart your agent, Raven's 70 tools are now available

03

Use it

ask your agent to audit a page, generate a design system, or check contrast; it calls the right tool automatically.

mcp-client.json · manual config
{
  "mcpServers": {
    "ravenmcp": {
      "command": "npx",
      "args": ["-y", "@ravenmcp/server"]
    }
  }
}

get_principlesREAD

Get design principles relevant to a UI context. Returns usability heuristics, Laws of UX, Gestalt principles, accessibility rules, typography, color theory, mobile UX, and responsive layout.

Parameters

contextstringrequired
What you're designing — e.g. "signup form", "pricing page", "mobile nav", "dark dashboard"
categoryenumoptional
Filter to: nielsen-heuristics, laws-of-ux, gestalt, accessibility, typography, color-theory, mobile-ux, responsive-layout, d4d
show 9 accepted values
nielsen-heuristics · laws-of-ux · gestalt · accessibility · typography · color-theory · mobile-ux · responsive-layout · d4d
formatenumoptional
"full" (default) | "checklist" | "brief"
Example usage

"Build a pricing page" / "What accessibility rules apply to forms?" / "Check this against Nielsen's heuristics"

agent call
tool: get_principles
arguments:
  context: "dark pricing page"
  category: "accessibility"
  format: "checklist"

Data Structure

route / schema

Every audit returns a structured object: findings[] (each with severity, rule, location, fix), a summary score, and calibration_hint when a taste profile is bound.

The stable shape lets an agent summarize findings, apply a targeted change, and compare a second audit without parsing prose.

audit-result.json
{
  "findings": [
    {
      "severity": "high",
      "rule": "wcag-text-contrast",
      "location": ".pricing-card .eyebrow",
      "fix": "Raise contrast from 2.8:1 to at least 4.5:1."
    },
    {
      "severity": "medium",
      "rule": "tap-target-size",
      "location": "nav .menu-trigger",
      "fix": "Increase the interactive area to 44 × 44px."
    }
  ],
  "summary": { "score": 72, "high": 1, "medium": 1 },
  "calibration_hint": "Project prefers restrained motion and one accent hue."
}

FAQ

route / faq
Does this replace a design system?

No. Raven can generate and audit a system, but your product team still owns the decisions, components, governance, and maintenance.

Does it work with any coding agent that supports MCP?

Yes. Add Raven as an MCP server in the client's configuration. Tool selection and presentation vary by agent.

Is my design data used to train models?

No. Raven processes the context needed for the requested tool and does not use your design data to train models.

What's the difference between the free and team tier?

The free tier covers individual use and the core tool set. The team tier adds shared taste profiles, governance, and controls for collaborative environments.

Can I self-host?

Yes. Run the MCP server in your own environment and connect clients to that instance.
