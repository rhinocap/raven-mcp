v1.12.0

minor Jun 21, 2026

Raven v1.12.0 — compact audit responses + truer contrast measurement

Added

  • compact response mode for audit_page, evaluate_design, and audit_url — pass compact: true to get back just the scores, violations, and fix priorities, dropping embedded screenshots and full principle bodies for a far lighter payload. Off by default.
  • suggest_contrast_fix — given failing WCAG color pairs, returns the minimal foreground (or background) change that clears the AA/AAA target, with the achieved ratio. Pairs directly with audit_contrast.

Changed

  • audit_contrast now composites each text element's background over its full ancestor stack instead of a single layer over white — eliminating false AA failures on dark and layered UIs (e.g. a translucent pill over a dark hero) and reporting the true effective background. Existing single-background callers are unchanged.

v1.11.0

minor Jun 21, 2026

Raven v1.11.0 — device-frame crop audit + palette & spacing discipline principles

Added

  • audit_device_frame — flags cropped content in device-mockup frames (phone/MacBook screenshots, app-preview clips): object-fit:cover aspect-ratio crop loss, baked-in pan/zoom (Ken Burns) drift, and content truncated at a frame edge. Catches the case where a 16:9 clip in a ~1.82-aspect screen cutout silently slices the bottom.
  • color-systems principle — palette-size discipline: keep a page at or under 10 distinct colors with a role-based token set (surface, border, text, accent, semantic), surfaced through get_principles, search_knowledge, and evaluate_design.
  • spacing-systems principles — an 8px base-unit grid (4px half-step) and a limited ≤7-token spacing scale, aligned to the spacing/base-unit and spacing/scale-count audit rules.

v1.10.0

minor Jun 19, 2026

Raven v1.10.0 — content, typography & tap-target audits

Added

  • audit_content — per-item content evaluation with a pass/warn/fail verdict, matched UX-writing principles, and a before→after rewrite for each heading, CTA, label, metric, caption, or prose block.
  • audit_typography — detects the dominant modular scale over rendered text and flags off-scale sizes, inconsistent line-heights, and bloated weight ladders.
  • audit_tap_targets — WCAG 2.5.5 / Apple 44pt web tap-target audit; emits a per-element fix table with the exact CSS to reach the minimum, worst-first.

Changed

  • Blank-video detection now classifies each case (preload-none, autoplay-blocked, empty-src, decode-error) so a genuinely broken video is no longer rubber-stamped as a lazy-load artifact.
  • iOS capture gains a snapshot-wiring preflight that catches setup gaps before build iterations are spent.

v1.9.0

minor Jun 19, 2026

Raven v1.9.0 — live render-and-capture audits

Added

  • audit_url — Layer 0 render-and-capture audit. Renders a live URL at each viewport × theme, scroll-settles (firing whileInView reveals and playing videos), fires hover/click/focus, then runs the full check engine plus new pixel checks: sliced-image edge-symmetry and hover-state white-wash detection. Every finding is tagged confirmed / likely-artifact / inconclusive with its evidence. This is the tool that catches real-world visual nits invisible to HTML-string audits: cropped images, blank videos, hover white-wash, and hidden-on-mobile content.

v1.8.0

minor Jun 18, 2026

Raven v1.8.0 — iOS audit roadmap (contract, parity & a11y)

Added

  • audit_contract — verify a wire contract (token list / field set / schemaVersion) is identical across iOS, proxy, and Android source; catches the prefix-ordering bug that silently corrupts directive parsing.
  • audit_api_contract — runs adversarial queries against a live endpoint and returns shape-valid / shape-invalid / confident-wrong / uncertain per query.
  • audit_parity — compares iOS and Android snapshots against named spatial relationships and reports per-relation match/mismatch with measured deltas.
  • audit_ios_a11y — scores an iOS snapshot for missing labels/traits, sub-44pt targets, contrast, Dynamic-Type clipping, and VoiceOver order.
  • Device-capable iOS capture orchestration with freeze-frame interactions for pixel-stable animation states.

v1.7.0

minor Jun 18, 2026

Raven v1.7.0 — contrast, responsive & asset-integrity audits

Added

  • audit_contrast — exact WCAG 2.1 contrast ratios for every text element on a rendered page, with delta-to-pass for each failure.
  • audit_responsive_visibility — renders a page at multiple breakpoints and flags content shown on desktop but hidden on mobile, categorised as likely-oversight vs intentional.
  • audit_asset_integrity — detects content cut off inside a correctly-sized export, which dimension/ratio checks cannot catch.
  • audit_page gains live-URL rendering, scripted interactions, an adversarial_verify pass, and a containerMaxWidth token check.
  • evaluate_design gains before/after screenshot diffing to confirm a fix actually changed the rendered output.
