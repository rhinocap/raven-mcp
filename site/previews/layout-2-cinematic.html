Design Intelligence for AI Agents

Give your AI design intelligence.

Raven is an open-source MCP server that gives Claude and other coding agents world-class design judgment — audits, design systems, brand, content, and creative scoring.

$ claude mcp add raven -- npx -y raven-mcp
