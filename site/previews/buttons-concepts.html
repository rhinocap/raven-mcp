Get Started — CTA Concepts

Three distinct directions for the primary install call-to-action. Each fully interactive. Compare, then pick.

Concept A

Command-first

The command IS the CTA. Developers reach for the terminal, not a button — so make the command the primary affordance: large, copyable, instantly confirming. Docs take a back seat.

Concept B

Segmented Split

One unified capsule, two intentions: a bold primary action and an attached command-copy. Premium, compact, decisive — the command is accessible without dominating the visual hierarchy.

Concept C

Aurora Capsule

Maximum polish. An animated cyan aurora border signals energy and precision — the button invites the click, copies the command, and rewards with a satisfying checkmark. Award-bait craft.
