# Code of Conduct

Raven MCP adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

The Contributor Covenant is a widely-used standard. Read the full text at the link above.

## In short

Be respectful. Assume good intent. Critique ideas, not people. No harassment of any kind. Keep discussions on-topic and focused on the work.

## Scope

This code of conduct applies to all project spaces — issues, pull requests, discussions, and any communication channels linked from this repository. It also applies when an individual is officially representing the project in public spaces.

## Reporting

If you experience or witness behavior that violates this code, report it to:

**drew@ravenmcp.ai**

Reports are kept confidential. The maintainer will review every report and respond with a course of action proportionate to the conduct.

## Enforcement

Maintainers are responsible for clarifying and enforcing this code. They have the right and responsibility to remove, edit, or reject contributions that do not align with it, and to ban contributors for behavior they deem inappropriate, threatening, or harmful.
