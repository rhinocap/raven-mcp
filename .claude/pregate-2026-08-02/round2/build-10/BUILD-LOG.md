## Choices made

- **Accent is the Undo button's text color only** — punctuation on the one interactive element that carries real signal (an action, not decoration), matching `COLOR-accent-punctuation-not-fill` / `COLOR-control-signal-only`. Everything else in the snackbar (surface, border, dismiss icon, timer) stays monochrome.
- **Dwell timer instead of a decorative progress bar**: a 2px hairline in `--line-strong` that linearly drains over the hold duration. It's structural (tells the user how long they have to undo before the save commits) rather than decorative, per `MOTION-reveals-structure`.
- **No token in DESIGN.md covers a multi-second auto-dismiss hold**, so I added one locally: `--duration-snackbar-hold: 6000ms`, following the same `var(--token, fallback)` discipline as every other value, and included it in the `prefers-reduced-motion` clamp block (down to 0.001ms) alongside the existing three motion tokens.
- **Entrance/exit**: opacity 0→1 + `translateY(20px)→0`, using `--duration-base`/`--ease-out-quart` — the same restrained fade-and-rise the taste profile's precedent corpus explicitly prefers over theatrical transforms (rotateX/skewX were flagged as a violation elsewhere in the corpus).
- **Explicit dismiss ≠ undo**: clicking the × commits the optimistic save immediately (skips the wait) rather than reverting it — dismissing an "it saved" toast shouldn't silently discard the user's edit. Undo reverts and shows a brief, non-actionable "Change reverted" toast (no Undo action on an already-undone action).
- **Tap targets**: both Undo and the dismiss icon button are 44px minimum per `SPACING-tap-targets-44px`, even though the dismiss icon itself is 16px — padding carries the hit area.
- **Icon**: inline SVG `stroke="currentColor"`, no hardcoded stroke color, per `ASSET-icon-stroke-current-color`.
- **No box-shadow-as-glow**: kept a small neutral (non-colored, non-blurred-hue) elevation shadow for the snackbar surface — flat hairline border does the primary separation work; avoided anything resembling a card-soup drop shadow or glow/neon per `COLOR-no-gradient-no-glow` / `OTHER-no-shadcn-defaults`.
- **Demo harness**: a single "Save change" button flips a "Project title" field to a new value instantly (the optimistic part), fires the snackbar, and offers three exit paths to exercise by hand — auto-dismiss after 6s (commits), Undo (reverts + shows a brief non-undoable confirmation), and explicit dismiss × (commits immediately, skipping the wait). Escape key also dismisses.
- Fonts are declared as `var(--font-body/--font-serif/...)` with real fallback stacks (no licensed Untitled Sans/Domaine/Geist files are available in this fixture context) — token discipline is satisfied even though the exact typeface isn't loaded.
