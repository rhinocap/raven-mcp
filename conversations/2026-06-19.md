## Mistakes & lessons (session 2)

| Mistake | Type | Rule added |
|---------|------|-----------|
| Tried to parse `d['results']` from Workflow output; actual key was `result` (wrapped `{summary, agentCount, logs, result}`); required a second jq probe | Speed gap (REPEAT) | Rule already in CLAUDE.md: "Probe workflow/agent output shape before parsing — ALWAYS." | Attempted Edit on `index.ts` and `manifest.json` without a prior Read; tool rejected with "File has not been read yet" (twice) | Speed gap | Standard process. Always Read the target file before any Edit, especially import sections and JSON files touched only at the end of a build. |

A `false` with no explanation is a silent-failure mode worse than not running. |
| MCP smoke script written to `/tmp/raven-smoke.mjs` failed: ESM bare imports (`@modelcontextprotocol/sdk/...`) can't resolve without `node_modules` on the lookup path; required moving into repo | Speed gap | When writing MCP SDK smoke scripts that import bare `@modelcontextprotocol/...` packages, write the file inside the project repo directory (ESM resolution walks up from the script's location to the nearest `node_modules`). `/tmp` has no `node_modules`. |
