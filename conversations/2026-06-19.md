## Mistakes & lessons

| Mistake | Type | Rule added |
|---------|------|-----------|
| Subagent returned base64 data URIs for sliced/clean PNGs; sliced URI was corrupted in transit — case 4 (slice detection) failed first probe | Accuracy gap | Never inline agent-returned binary/base64 in fixture files — always write to disk and reference by path |
| Initial probe script resolved dist import from `/private/tmp/` instead of repo | Speed gap | When writing one-off probe scripts, include the absolute repo path in the import explicitly |
| Shell heredoc with `${VAR}` in eval context gave "bad substitution" — needed to write script to a file | Speed gap | For git ops with embedded variables, write the script to a file first rather than inlining in eval/heredoc |
| Portfolio ledger push was non-fast-forward (another instance moved origin/main) — needed 2 extra round-trips for worktree recovery | Speed gap | The parallel-instance collision check applies to ALL pushes across ALL repos in a session, not just the primary repo |
