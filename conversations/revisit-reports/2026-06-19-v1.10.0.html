Mistakes & lessons
Repeat Workflow output key mismatch (3rd session)

Tried to parse d['results'] from the Workflow result. Actual shape: {'summary', 'agentCount', 'logs', 'result'}. Required a second jq keys probe.

Status: Rule already in ~/.claude/CLAUDE.md ("Probe workflow/agent output shape before parsing — ALWAYS"). This is habit compliance, not a rule gap. The self-check must happen BEFORE the parse, not after the KeyError. No re-promotion needed; flagged as chronic execution gap.

Speed gap Edit without prior Read (×2)

Attempted Edit on index.ts and manifest.json without a prior Read. Tool rejected both with "File has not been read yet." Standard process, immediate recovery.

Rule: Read the target file before any Edit, especially import sections and JSON files only touched at the end of a build.

Accuracy gap Subagent preflight: boolean-false with empty guidance

Subagent-authored checkSnapshotWiring returned ready:false with empty guidance[] for the testTargets=[] boundary case. The harness would have printed a header with no bullets — technically not wrong, but useless to the caller. Required a follow-up fix + test.

Rule: When reviewing a subagent-authored gating function (ready, passed, ok), explicitly test the boundary case where the gate fires but the human-facing output (guidance[], issues[], suggestions[]) is empty. A false with no explanation is a silent-failure mode worse than not running.

Speed gap MCP smoke script in /tmp

Wrote /tmp/raven-smoke.mjs; ESM bare imports (@modelcontextprotocol/sdk/...) failed because there's no node_modules in /tmp. ESM resolution walks up from the script file's location.

Rule: MCP SDK smoke scripts must live inside the project directory, not /tmp. Write to the repo, delete after.
